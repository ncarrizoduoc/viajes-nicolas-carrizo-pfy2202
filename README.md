# Proyecto: Página para agencia de viajes

El presente proyecto corresponde a una página para una agencia de viajes. En ella se pueden explorar distintos destinos ofrecidos por la agencia. Para cada destino se pueden visualizar opciones de vuelos y alojamiento.

## Herramientas utilizadas

El proyecto se construyó usando React (con Vite). En él se utilizan llamadas **REST** (simuladas con MSW) para obtener información de los destinos. Por otra parte, utiliza **GraphQL** para obtener información detallada de cada destino de viaje.

## Cómo ejecutar

Para ejecutar el proyecto se puede acceder al sitio publicado en GitHub Pages usando el siguiente enlace: 

``https://ncarrizoduoc.github.io/viajes-nicolas-carrizo-pfy2202/``

También se pueden descargar los archivos para ser ejecutados de forma local (es importante instalar las dependencias e inicializar MSW para simular las llamadas REST)
